# @react-viz-composer/kit

Semi-finished chart building blocks for ReactVizComposer: `Axis`, `Grid`, `Tooltip`, `Legend`, `MarkLine` / `MarkPoint` / `MarkArea`, `Crosshair`, `Brush`. Display-only — pass data and wire events yourself.

```bash
npm install @react-viz-composer/kit @react-viz-composer/core
```

Peer: `@react-viz-composer/core`, `react`, `react-dom` (`>=18`).

Reference chart implementations live in the repo under `apps/charts` and are **not** published.

Docs: [react-viz-composer](https://github.com/1815304465/react-viz-composer).
