# react-viz-composer

Umbrella package: re-exports [`@react-viz-composer/core`](https://www.npmjs.com/package/@react-viz-composer/core) (engine + shapes) and [`@react-viz-composer/kit`](https://www.npmjs.com/package/@react-viz-composer/kit) (Axis, Grid, Tooltip, Legend, marks, …).

```bash
npm install react-viz-composer
```

```tsx
import ReactVizComposer, { Rect, Axis, Grid } from 'react-viz-composer';
```

Requires `react` and `react-dom` (`>=18`).

Full docs: [GitHub](https://github.com/1815304465/react-viz-composer).
