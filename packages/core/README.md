# @react-viz-composer/core

Declarative SVG/Canvas hybrid rendering engine for React. Shape primitives (`Rect`, `Ellipse`, `Line`, `Path`, `Text`, `Image`, `Points`, `Group`, `Animation`, …) are pure proxies; rendering happens in the engine layer.

```bash
npm install @react-viz-composer/core
```

Requires `react` and `react-dom` (`>=18`).

Docs and examples: [react-viz-composer](https://github.com/1815304465/react-viz-composer).

For a single install that also includes chart kit helpers, use [`react-viz-composer`](https://www.npmjs.com/package/react-viz-composer).
