# react-viz-composer

Declarative SVG/Canvas hybrid rendering engine for React. Shape primitives (`Rect`, `Ellipse`, `Line`, `Path`, `Text`, `Image`, `Points`, `Group`, `Animation`, …) are pure proxies; rendering happens in the engine layer. Also includes chart helpers: `Axis`, `Grid`, `Tooltip`, `Legend`, marks, `Crosshair`, `Brush`.

```bash
npm install react-viz-composer
```

```tsx
import ReactVizComposer, { Rect, Axis, Grid } from 'react-viz-composer';
```

Requires `react` and `react-dom` (`>=18`).

Full docs: [GitHub](https://github.com/1815304465/react-viz-composer).
